## 技能地圖

### 1. 核心技能分析

| Skill | 功能 |
|-------|------|
| us-stock-analysis | 個股基本面分析、估值、財務趨勢 |
| health-scoring | Altman Z-Score（破產風險）、Piotroski F-Score（財務強度） |
| chart-generation | 股價圖表生成（180天走勢） |

### 2. 篩選工具

| Skill | 功能 |
|-------|------|
| canslim-screener | CANSLIM 成長股篩選 |
| value-dividend-screener | 價值 + 高股息篩選 |
| stock-screener | 一般股票篩選 |

### 3. 市場分析

| Skill | 功能 |
|-------|------|
| market-news-analyst | 市場新聞分析 |
| market-environment-analysis | 市場環境分析（全球市場、風險偏好） |
| institutional-flow-tracker | 法人資金流向追蹤（13F filings） |
| technical-analyst | 技術分析（均線、RSI、MACD 等） |

---

## 實作方向

### 1. 建立投資知識庫

收集並整理：
- 投資經典書籍
- 知名投資人觀點
- 技術分析教學
- 基本面分析原則

### 2. 開發選股流程

```
輸入條件 → AI 篩選 → 技術分析 → 風險評估 → 推薦標的
```

### 3. 監控與提醒

- 設定條件監控
- 價格到了主動通知
- 定期生成報告

---

## 風險提示

> [!warning] 重要提醒
> - AI 只是輔助工具，不能保證獲利
> - 投資有風險，入市需謹慎
> - 建議先模擬交易驗證策略
